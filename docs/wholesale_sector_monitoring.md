# Sector multistate histories and model-bound monitoring

Run `examples/wholesale_sector_monitoring.py` or native `run_wholesale_sector_monitoring()`. Both accept `data`, `verify_reference` and `artifact_paths`; R additionally accepts an explicit shared `engine_path`. The shared `specialized_monitoring` engine performs the actual multistate fit, distribution test and PD drift calculation. Seven sector resources bind their actual frozen component models and calibration artifacts from `wholesale_sector_governance`.

Historical default → cure → redefault paths distinguish first-hit probability from current default occupancy. For the seven 20-obligor histories, first-hit levels are 1/20, 2/20, 3/20, 2/20, 1/20, 1/20 and 2/20. First hit stays fixed after cure while default occupancy falls to zero and later rises upon redefault. These are observed synthetic state transitions, not repeated independent annual defaults.

Three separately identified March, April and May 2024 cohorts each contain 20 mature independent synthetic borrowers. Their one-year outcomes mature in 2025. Forecasts use the source model's preserved transformed input coordinate and sealed holdout calibration; no later information is backdated. Cohorts deliberately hold this risk coordinate fixed to isolate calibration monitoring. Each frozen model is reloaded, its knowledge cutoff checked and every stored PD matched against actual prediction. A tampered prediction fails even when reference assertions are disabled.

Default counts increase from d to d+1 and d+2 across the three cohorts. Residuals are observed default rate minus actual mean frozen PD. The independent EWMA is `state = 0.5*state + 0.5*residual`; the reported diagnostic uses its absolute value. Null paths and alert calibration are explicit prespecified synthetic monitoring inputs, not claimed to be estimated from these same evaluation outcomes. This PIT monitoring diagnostic does not imply a TTC calibration.

A separate feature-monitoring sample shifts two frozen-design coordinates by sector-specific amounts 0.15, 0.25, 0.35, 0.45, 0.20, 0.10 and 0.30. Its independent Wasserstein distance equals that shift. All 24 permutations of the pooled four observations are supplied. This sample is a distinct feature diagnostic, not a claim that the fixed-coordinate outcome cohorts also have shifted covariates.

The shared example's additive `reference.cohort_pd` supplies the sector's actual forecast probability to its independent oracle. The original specialized fixture omits this field and retains its exact 0.1 benchmark behavior. Default tests execute all seven real multistate fits and both monitoring diagnostics, plus model-bound forecast tampering controls. The packaged resources expose all observations and assumptions.
