# Frozen loss, survival, migration and population backtests

These functions return a `CalcResult` whose value has `artifact_type='ValidationResult'`. Metrics, applicability, uncertainty, p-values and decisions are separate. Descriptive results have `p_value=None` and decision `NOT_ASSESSED`; successful execution does not mean a model passed validation. Excluded observations are counted by reason, with prediction IDs, repeated entity counts, sampling clusters and actual input fingerprints. Empirical performance on another population is not established by synthetic software tests.

## Shared dated design

`design` records `model_id`, `model_version`, `parameter_version`, `data_fingerprint`, `population_id`, `split_id`, `prediction_origin='HOLDOUT'/'EXTERNAL'`, `evaluation_cutoff`, and `target`. Target fields are event `default`, positive horizon, unit days/months/years, probability measure and conditioning. Outcome backtests require `PHYSICAL`; descriptive population drift may describe either measure. An optional context must agree with target fields and have knowledge date equal to evaluation cutoff.

Loss/migration observation records contain unique `prediction_id`, `entity_id`, `cluster_id`, `segment`, `as_of`, `forecast_known_at`, `horizon_end`, matching model/parameter identities and `outcome_known_at`. Forecast knowledge cannot follow its observation date. Calendar horizons require whole days or whole months, with month-end clamping. Outcome metrics use mature windows and outcomes known by evaluation; future, unknown or incomplete observations are never fabricated as nondefaults. Declared identities and provenance are checked, not authenticated.

`uncertainty='none'` returns no interval. `cluster_bootstrap` requires at least two distinct declared sampling clusters and at least two supplied resamples. Each resample lists the original number of cluster IDs with replacement; all rows of each selected cluster move together. Type-7 percentile intervals are conditional on the frozen forecast and nuisance models. If any supplied draw cannot estimate a metric, its interval is non-estimable rather than silently discarding that draw. A degenerate interval is flagged. Weight-based effective sample size is a concentration diagnostic, not a claim of that many independent observations. Caller cluster choices must address economic entity, household/group and repeated-forecast dependence.

## LGD

`lgd_backtest(records, design=..., workout_policy=..., uncertainty=..., ...)` requires default-conditioned targets. Each row adds `default_date`, `predicted_lgd`, `workout_status='OPEN'/'CLOSED'`; closed rows add `workout_closed_at`, `realized_lgd`, `ead_at_default`. Default must fall between forecast date and horizon end (default-date LGD forecasts are permitted). Final closure follows default and precedes the final outcome's knowledge date. Open rows never provide a realized LGD, even if a partial estimate or interim field happens to be present.

A `workout_policy` declares a reference and either:

* `method='closed_only'`: descriptive completed-workout population, explicitly selected on closure;
* `method='ipcw'`: supplied completion probabilities with `identification='closure_independent_of_final_lgd_given_recorded_covariates'`, frozen `model_fingerprint`, `model_known_at` before forecasts and positive interior `minimum_observation_probability`. Every row provides `observation_probability` in [0,1]. Below-threshold rows are excluded and the estimand is explicitly reduced to the supported subpopulation. The routine checks the contract, not the truth of the identification assumption.

Completed observations receive weights 1 or inverse completion probability. Count-weighted and EAD-weighted error summaries are reported separately overall and by segment. Bias is **prediction minus outcome**; MAE, RMSE, means, weight sums, effective sample size and row bias contributions are returned. Contributions sum to reported bias. Supplied cluster draws provide intervals for both overall and segment summaries. IPCW uses self-normalized Hájek ratios, conditional on the supplied closure model; no closure model is refitted in validation. Zero EAD contributes no EAD-weighted information but remains in the count view. Raw economic LGD is not clipped to [0,1]. Closed-only performance is not a valid full-default-population claim without a selection argument.

## EAD and CCF

`ead_backtest(records, design=..., weighting_policy=..., uncertainty=..., ...)` also requires default conditioning; the design and rows declare matching currency. Rows add `default_date`, nonnegative `predicted_ead`, `realized_ead`, `realized_ead_date`, `drawn_at_reference`, and `limit_at_reference`. EAD forecasts precede default strictly and realized EAD uses exactly that default date. A weighting policy declares method `equal`, `reference_limit`, or `supplied` and a reference; the last reads nonnegative row `weight`.

Unweighted and selected-weight summaries remain separate, overall and by segment. CCF is derived consistently as `(EAD_default - drawn_reference)/(limit_reference - drawn_reference)` for predictions and observations. A fully drawn line has zero denominator; an overlimit line has negative denominator. Both receive explicit undefined CCF, not zero. They remain valid EAD observations. CCF is not clipped, so negative or above-one conversion can be observed. Currency/default/horizon mismatches are rejected. Zero selected weights do not create information; an empty weighted summary is non-estimable.

## Survival

`survival_backtest(predicted_event_curves, observations, horizons=..., censoring=..., design=..., uncertainty=..., ...)` accepts a row-by-horizon matrix of nondecreasing cumulative default probabilities. The target conditions on `performing`. Observations add nonnegative `observed_time` and Boolean `event`; a false event indicator means right censoring, not an observed zero default label.

The design explicitly declares `days_per_time_unit`: 1 for days; 30, 365/12 or 365.25/12 for months; 365 or 365.25 for years. These are elapsed-time bases, not calendar-month interpolation. Row horizon end must equal forecast date plus the ceiling of target horizon times this factor. Follow-up cannot be known before forecast date plus the ceiling of observed time times the factor. Horizons are positive, increasing and within the target horizon. Unknown/future follow-up records are excluded; partially observed eligible subjects remain in the censoring estimator's denominator.

`censoring` includes a reference and one of:

* `complete_followup`: every eligible nonevent is observed **strictly beyond** the largest horizon;
* `frozen_ipcw`: nonnegative increasing `times`, nonincreasing survival values in [0,1], `support_end`, an interior `minimum_survival`, model fingerprint/knowledge date before forecasts, `tie_rule='event_before_censoring'`, and `independence_assumption='censoring_independent_of_event_features_and_across_clusters'`.

The supplied censoring curve is a right-continuous step function G(t)=P(C>t), one before its first knot. This marginal model assumes censoring independent of event times and covariates and independent across declared sampling clusters. Conditional or informative censoring requires an appropriate different estimator; a marginal curve cannot fix it. The routine neither fits G on test outcomes nor extrapolates its declared support.

At horizon h, observed cases satisfy event and time <= h and receive 1/G(time-). Controls require observed time > h and receive 1/G(h). Censored subjects at or before h contribute no invented label. The Brier numerator uses weighted squared probability errors and divides by **all eligible subjects**, not by the sum of IPCW. Finite-sample IPCW Brier can exceed one. Horizons outside support or below the declared positivity threshold have no reported metric.

Cumulative/dynamic AUC compares these cases and controls from different clusters, weights both observations and gives half credit to risk-score ties. No eligible case/control pairs means no AUC. Truncated concordance uses the final-horizon PD as the fixed risk score and comparable event times t_i <= last horizon, t_j > t_i from different clusters. Event-time ties are not comparable. Pair observation probability is G(t_i-)*G(t_i); its inverse reduces to Uno's 1/G² with continuous censoring. This explicit boundary convention handles event-priority ties without substituting a zero label. Score ties get half credit. The concordance ratio, pair mass and time/score horizon are reported.

An integrated Brier summary uses trapezoidal integration over the supplied grid divided by that grid's interval length; it is not exact continuous-time integration and requires at least two supported points. Actual contributions, case/control/censoring counts, IPCW concentration and cluster-bootstrap intervals are available. Intervals hold G fixed and do not include nuisance-model estimation uncertainty.

The [official Brier documentation](https://scikit-survival.readthedocs.io/en/stable/api/generated/sksurv.metrics.brier_score.html), [dynamic AUC](https://scikit-survival.readthedocs.io/en/stable/api/generated/sksurv.metrics.cumulative_dynamic_auc.html) and [IPCW concordance](https://scikit-survival.readthedocs.io/en/stable/api/generated/sksurv.metrics.concordance_index_ipcw.html) provide the standard censored-score background. The event-left/control-right discrete-boundary and cross-cluster conventions above are explicit extensions: independently multiplying the two observation probabilities supplies their pair weighting. They do not claim a general solution to informative censoring.

## Population stability

`population_stability(reference, current, binning=..., metrics=..., smoothing=..., design=..., reference_weights=None, current_weights=None)` reports descriptive distances. Add `reference_as_of` and `current_as_of` to design. Binning declares ID/version, knowledge date before both samples and either numeric strictly increasing finite `cutpoints` plus ordered `reference_support`, or fixed categorical `levels`.

Numeric cutpoints put equality into the lower bin; missing is a separate bin. Categorical data reserve separate missing and unknown-category bins. Novel categories or observations outside declared reference support are counted. Reference/current weighted missingness and its change are separate diagnostics. The bins never refit on current data.

Metrics may be `psi`, `jsd`, and numeric `wasserstein`. PSI uses the explicitly supplied nonnegative pseudocount in each fixed histogram cell. Without smoothing, a positive mass against zero gives infinite PSI, represented by null plus `INFINITE`; two zero masses contribute zero. JSD is the symmetric half-weight KL divergence against the mixture using **unsmoothed empirical masses**, natural logarithms and the 0*log(0) limit. Numeric Wasserstein is the first raw-value distance conditional on nonmissing observations; no meaningful categorical metric is invented. Empty weighted populations or absent nonmissing numerical support are non-estimable. These statistics have no universal significance threshold or automatic concept-drift claim. For designed permutation testing use the monitoring drift API.

## Rating migration

`rating_migration_backtest(records, predicted_transition_matrices, states=..., state_contract=..., design=..., uncertainty=..., weights=None, ...)` accepts one common K-by-K matrix or one per forecast, all aligned to `states`. Conditioning is `origin_state`. Matrices are nonnegative, stochastic within 1e-12 and never renormalized. State contract declares scale ID/version, reference/knowledge date before forecasts, disjoint `default_states`, `cure_states`, `exit_states`, and explicit `absorbing_states`. Absorbing rows must be exactly identity; default is absorbing only when declared so.

Records add matching scale ID/version, `origin_state`, `observation_status='OBSERVED'/'CENSORED'`, and for observed endpoints `destination_state`, `state_observed_at`. A nonabsorbing destination must be observed exactly at horizon end. Earlier observations imply the endpoint only for a declared absorbing state. A censored endpoint is never silently a self-transition. An observed departure from an absorbing origin is reported as a data/definition violation and excluded, not counted as proof of perfect prediction.

Per-origin observed/expected counts, probability rows, residuals and scores remain separate. Empty origin grades have no estimated probabilities, residual goodness or perfect score. Multiclass Brier is the sum of K squared probability errors (range 0 to 2). Exact log loss retains impossible observed transitions as null plus `INFINITE`. Default destination share is not mislabeled first-default incidence; cure and exit are distinct states. Shared cluster draws produce actual score and transition-proportion intervals; empty bootstrap origins make their intervals non-estimable. All given weights and the normalized per-record matrix fingerprint remain in the report.

The [BCBS validation studies (2005)](https://www.bis.org/publ/bcbs_wp14.pdf) provide methodological background for separate PD/LGD/EAD validation. These routines make no claim of current regulatory approval. Independent software tests cover closed/open loss selection, hand-weighted bias, undefined CCF, the no-censoring binary Brier identity, censoring limits, exact migration counts, infinite scores, missing origins and frozen-bin divergence limits. Native R tests load an independently installed package; neither a source-tree workaround nor Python bridging is required.
