# Retail pool validation

`retail_pool_diagnostics(fitted_model, pool_assignments, assignment_inputs, predictions, cohort_outcomes, workouts, links, estimation_profile, *, design, previous_assignments=None, uncertainty='none', cluster_resamples=None, confidence_level=.95, tolerance=1e-10, context=None)` validates frozen statistical retail pools. These are distinct from legally transferred asset pools.

Supply the real model and sealed assignments from `fit_retail_risk_pools` and `assign_retail_risk_pool`. `assignment_inputs` contains the exact assignment arguments except model and context. Assignment is replayed; labels never refit pool boundaries. All assignments need one frozen prediction and one relationship record. Predictions use the common dated validation row contract, plus `observation_id`, `pd`, nullable `lgd`/`ead`, `reference_exposure`, and explicit `excluded_from_training`/`excluded_from_calibration`. The design's five-field target and currency must match the richer pool target. Pool training must precede every held-out index. Forecasts may be individual or constant within a pool; no individual rank is inferred from a constant pool PD.

Each link record contains `observation_id`, `facility_id`, `obligor_id`, `household_id`, `risk_group_id`, `diagnostic_group`, and `known_at`. Relations and diagnostic groups must be available by the index date. The prediction entity is the declared facility/obligor default unit. One prediction per default unit is required; aggregate facilities before submitting an obligor-target cohort. Household links are used for concentration and dependence, never to propagate default labels. Connected obligors, households and risk groups must remain in one sampling cluster when bootstrap intervals are requested.

Cohort/workout records and the dated weighting profile follow `estimate_pool_risk_parameters`. Negative outcomes additionally need `complete_through` covering the full horizon. Missing, censored and immature outcomes remain excluded. Closed-workout LGD, actual default EAD and whole-horizon PD have separate denominators. The existing recovery-discounting, economic-LGD and realized-CCF arithmetic produces observed summaries only; it does not replace frozen forecasts. Independent-binomial intervals and independent-episode standard errors are deliberately omitted here. Requested uncertainty comes from the actual supplied cluster draws and conditions on frozen pools/forecasts; missing or non-estimable bootstrap replicates suppress the affected interval.

Output includes count- and exposure-weighted PD metrics, within-pool discrimination applicability, between-pool mean-score discrimination, separate LGD/EAD prediction errors, and predeclared group mean residuals and their range. The residual range is descriptive, with cluster uncertainty where requested; a small range in a tiny sample is not a homogeneity acceptance decision. Concentration tables report count/exposure shares and Herfindahl indices for obligors, households and connected risk groups.

Optional previous sealed assignments use each link's `previous_observation_id`. Prior assignments must be strictly earlier and known by the current index. A changed model definition or unassigned endpoint makes the migration comparison inapplicable. Missing prior observations remain explicit.

Independent example: three defaults among four units give count PD 0.75. Default exposures 100+300+200 over total 1,000 give exposure PD 0.6. Closed LGDs 0.6 and 0.2 with EAD weights 100 and 300 give observed LGD 0.3, so frozen LGD 0.4 has bias +0.1. A third open workout contributes its observed EAD but no final LGD. Default EADs 100, 300, 200 against frozen 150 give bias −50. These calculations require neither equal default frequencies nor invented future recoveries.

[BCBS CRE36, published 2022-12-08, paragraphs 36.16–17 and 36.24](https://www.bis.org/committees/bcbs/basel-framework/standard/cre/36/inforce/2023-01-01/published/2022-12-08) motivates borrower/transaction/delinquency differentiation, separate pool PD/LGD/EAD and concentration diagnostics. It is a dated methodological reference, not a claim of current regulatory approval.
