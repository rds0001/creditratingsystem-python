# Survival, competing events and multistate histories

These eight methods use physical event probabilities, explicit model-clock units and data-only frozen artifacts. Every estimator returns a `FitResult` containing a serializable `ModelArtifact`. `predict_event_curves` applies the frozen parameters without loading a backend estimator or refitting anything. Python fitting uses statsmodels and lifelines; native R uses survival and the library's native GLM estimator. Nonparametric products and risk-set arithmetic are evaluated directly in both languages.

All fits require `target`, `training`, `model_id` and `model_version`. Targets contain `event`, positive `horizon`, `time_unit` (`days`, `months`, `years`), `probability_measure="PHYSICAL"` and `conditioning`. Training metadata records `data_fingerprint`, `split_id`, ISO `known_at`, and optional `data_origin`. Inputs must already use the target's time units; the methods do not silently convert calendar dates or learn feature transformations. Numeric feature matrices have an explicit unique `feature_order`; a model without covariates uses a matrix with n rows and zero columns. Event indicators are numeric zero/one; null or missing outcomes are not zero.

## Kaplan–Meier with delayed entry

`estimate_survival_curve(entry_time, exit_time, event_indicator, weight_policy="frequency", ..., target=..., training=..., model_id=..., model_version=...)` estimates the product over observed event times. `entry_time=None`/`NULL` means zero entry; all intervals require `0 <= entry < exit`. At time t, an observation is at risk exactly when `entry < t <= exit`, so a subject entering at an event time does not enter that event's risk set. Events precede censoring at the same time.

Optional weights are nonnegative integer frequency counts with positive total. This interprets a weight as independently replicated observations, not a survey weight. The fitted curve records event/censor times, at-risk frequency, event frequency, censored frequency, survival, Greenwood sum and log-log interval endpoints. `confidence_level` defaults to .95. Independent subjects and noninformative censoring/truncation are required. Greenwood boundary intervals can degenerate at zero or one survival; diagnostics identify them as asymptotic, not exact small-sample bounds. Empty observation-risk intervals are recorded in the artifact; default prediction rejects horizons crossing them, while explicit flat continuation reports the unsupported intervals. Prediction conditions the frozen curve on surviving to the chosen landmark.

The interval and estimator choices follow the [survival `survfit` documentation](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/survfit.formula.html); tests independently compare native Greenwood/log-log calculations with that implementation.

## Cox counting-process models

`fit_cox_ph(start_stop_panel, X, feature_order=..., ties=..., strata=None, covariance="model_based", ...)` supports both `breslow` and `efron` partial-likelihood ties. Panel rows contain `entity_id`, `start`, `stop`, `event` and, when covariates exist, `covariate_time <= start`. Multiple intervals per subject must be contiguous and cannot continue after the terminal event. Covariates are constant within each row but may change at interval boundaries. `strata` supplies one baseline stratum per row; absent strata use `all`.

There is no Cox intercept: implicit intercepts and collinear designs are rejected. Python uses [statsmodels PHReg](https://www.statsmodels.org/stable/generated/statsmodels.duration.hazard_regression.PHReg.html); native R uses `survival::coxph`. Statsmodels' inclusive-entry lookup is adapted with the immediate representable successor of each start, enforcing the exact `(start,stop]` convention without moving event times. Separate regression fits estimate Efron/Breslow coefficients. The frozen baseline in both languages is explicitly **uncentered Breslow**, including when coefficient estimation uses Efron ties. This declared choice avoids backend-specific centering and baseline interpolation. No-covariate fits use direct risk-set arithmetic.

Model-based covariance assumes independent subjects under the counting-process likelihood; `cluster_robust` groups all rows by entity. Diagnostics include convergence information, partial likelihood, coefficient covariance, event-time sums of Schoenfeld residuals, and a PH score test. The PH test adds identity-time-by-covariate interactions, centers time over events, and eliminates coefficient nuisance information by its Schur complement. Global and per-feature chi-square statistics are returned when identifiable. Tests compare the nonzero global statistic independently with [`survival::cox.zph(transform="identity")`](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/cox.zph.html). The score diagnostic assumes independent subjects even when a robust coefficient covariance is requested; it is not a proof of proportionality or a multiple-testing correction.

## Parametric AFT models

`fit_aft_model(durations, events, X, feature_order=..., distribution=..., ...)` fits `weibull`, `lognormal` and `loglogistic` separately by full right-censored likelihood. Durations are positive and observed events contribute the density while censored observations contribute survival. The common frozen parameterization is

`log(T) = intercept + X beta + scale * epsilon`, with positive scale.

For Weibull, epsilon has minimum extreme-value CDF `1-exp(-exp(z))`; the usual Weibull shape is `1/scale` and its scale parameter is `exp(intercept+X beta)`. For lognormal, epsilon is standard normal. For loglogistic it is standard logistic, with usual shape `1/scale`. Coefficient covariance is stored in the common coordinates `(intercept, beta, log(scale))`, transforming the lifelines ancillary parameter as necessary.

Python uses the established [Weibull](https://lifelines.readthedocs.io/en/latest/fitters/regression/WeibullAFTFitter.html), [lognormal](https://lifelines.readthedocs.io/en/latest/fitters/regression/LogNormalAFTFitter.html) and [loglogistic](https://lifelines.readthedocs.io/en/latest/fitters/regression/LogLogisticAFTFitter.html) AFT fitters. Native R uses [`survreg`](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/survreg.html). Returned diagnostics verify the backend likelihood against each row's analytical contribution in the common parameterization. Independent tests additionally use the uncensored normal MLE, the Weibull profile score equation, the symmetric loglogistic scale equation and distribution-library log densities/survivals. AFT prediction requires a fixed covariate profile; a time-varying acceleration law is not inferred from arbitrary feature paths.

## Discrete hazards and partially observed periods

`fit_discrete_hazard(person_period_panel, X, feature_order=..., period_grid=..., link=..., partial_period_policy=..., ...)` supports logit and cloglog, with a fitted dummy intercept for each period and shared covariate coefficients. Panel rows use the Cox identity/start/stop/event contract plus a **zero-based** `period` and `interval_end_type` equal to `scheduled` or `censor`. A positive binary event must refer to a prespecified scheduled observation window, not an exact failure time used as an endogenous exposure endpoint. Exact event times belong in a continuous-time likelihood.

The declared risk interval must lie inside its period. An event removes later observations. `exclude_censored` requires entry at the period start, includes complete periods, and excludes incomplete censored periods instead of coding them as complete nondefaults. Partial positive-event windows are rejected in this mode. Exclusion does not identify hazards in the missing partial-window population without additional observation assumptions.

`cloglog_exposure` requires the cloglog link. It uses offset `log(observed_duration/full_period_duration)` under a constant within-period intensity. This gives valid survival contributions for noninformative partial censoring and grouped-event contributions for prespecified shorter windows. It does not substitute a Bernoulli likelihood for an exact event-time density. Prediction with logit requires whole fitted periods and boundary-aligned covariates/horizons; cloglog can integrate fractional periods with the exposure rule. This is a likelihood/observation-contract decision, not an automatic imputation of unobserved follow-up.

## Cause-specific and Fine–Gray event risks

`fit_cause_specific_hazards(start_stop_panel, X, event_types, feature_order=..., causes=..., ties=..., ...)` fits one Cox model per explicitly named cause. `event_types` contains a cause or null censoring; all terminal causes end the subject's at-risk history. A competing event is censored at its occurrence in another cause's fit. Each required cause must have observed events rather than receiving an invented zero hazard.

Prediction integrates every cause jointly at the union of baseline event times. At a frozen step with cumulative-hazard increments `dH_k`, total `dH=sum(dH_k)`, and survival immediately before it S, the updates are

`dF_k = S * (1-exp(-dH)) * dH_k/dH`, and `S_new = S*exp(-dH)`.

A zero total produces no change. This is the exact exponential/proportional-cause integration convention for each fitted increment; the parameterization is explicitly different from multiplying discrete empirical Aalen–Johansen transition fractions. It preserves `S + sum(F_k) = 1`, including simultaneous competing hazards and large increments. A cause CIF is not `1-exp(-H_k)` in a competing-risk model. The joint survival-weighted CIF interpretation is supported by the [survival competing-risks vignette, Section 2.1](https://stat.ethz.ch/R-manual/R-devel/library/survival/doc/compete.pdf).

`fit_fine_gray(event_times, event_types, X, cause_of_interest=..., feature_order=..., censoring_spec=..., ...)` estimates a selected-cause subdistribution hazard. This API uses fixed baseline covariates and right censoring from time zero. It does not invent post-competing-event time-varying features or a delayed-entry IPCW law.

The censoring specification requires `estimator="kaplan_meier"`, `independence_assumption="independent_within_censoring_group"`, and optional per-subject `groups`. A reverse Kaplan–Meier model is estimated separately per group; at tied times terminal events are removed before censoring events. Subjects with a competing failure at T remain in later selected-cause risk sets with weight `G(t-)/G(T-)`; still-observed subjects have weight one. Unsupported censoring denominators are rejected. Expanded risk rows, weights and censoring curves remain available for audit.

Weighted counting-process Cox estimation uses Efron ties (lifelines in Python, survival in R), with the same uncentered Breslow baseline convention as above. Both no-covariate risk arithmetic and nonzero regression fits are checked against the independent [`survival::finegray` expansion](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/finegray.html). The stored coefficient covariance is explicitly conditional on estimated IPCW, not a full repeated-sampling variance. For inference, resample original subjects and refit the censoring model as well. Prediction returns the selected-cause CIF; its complement is not all-event survival. Independently fitted Fine–Gray CIFs for several causes are not automatically a coherent joint distribution.

## Aalen–Johansen, cure and redefault

`estimate_multistate_transitions(event_history, states=..., allowed_transitions=..., initial_state=..., ...)` takes rows `{entity_id,start,stop,from_state,to_state}`. A null destination ends observation in the current state; a destination equal to the origin is a no-change observation. Intervals for one entity must be contiguous and state-consistent. A different destination must belong to the explicit directed graph. Repeated transitions, delayed entry, different starting states and cures are retained. All transition times are observed exact times, not an interval-censored snapshot history.

At each event time, each off-diagonal hazard increment is transition count divided by the number in the origin state just before that time; its diagonal is minus the row sum. The fitted transition product is `P=P*(I+dA)`. Artifacts store risk sets, transition counts/increments/products, occupancy from the declared initial state, and observation intervals. Absent-risk rows have an identity increment with unidentifiable outgoing intensity; that arithmetic convention is not proof of no risk. Prediction rejects positive mass in unsupported outgoing states by default; explicit `flat` continuation records these cases.

Transition-probability interpretation given a state/landmark requires a time-inhomogeneous Markov model (or a properly chosen state expansion that makes the history relevant to transitions part of the state). A single time-since-origination model does not automatically become a time-since-cure model. The clock and state definitions must match the collection question.

Current-state occupancy can fall after a cure. First-hit incidence is calculated with a separate absorbing projection of `event_states`, so a completed first default never disappears after cure. To predict redefault after cure, supply `initial_state="cured"`, the absolute cure landmark as `start_time`, and `event_states=["default"]`. The function does not attribute a causal treatment effect to collection actions; action-conditioned models require an independently justified compatible artifact/target contract.

## Frozen prediction and interchange

`predict_event_curves(fitted_model, covariate_paths, horizon_grid, feature_order=..., target=..., initial_state=None, event_states=None, start_time=0, extrapolation="error", quantile_levels=None, ...)` uses a nonnegative increasing **elapsed** horizon grid. Model history times and path start/stop coordinates remain absolute on the model clock. Feature order and the complete target must match the artifact.

KM/Aalen–Johansen require empty paths. Regression paths contain `path_id`, `start`, `stop`, numeric `covariates`, optional `stratum` (default `all`), and `covariate_time <= start`. Each path must cover the requested landmark and horizon contiguously. Unknown strata and feature/target mismatches fail. Empty feature arrays retain their shape through public Python/R JSON serialization.

The result value is `{horizon_grid,start_time,curves:[...]}`. Each curve has `path_id`, `survival`, `cumulative_incidence` keyed by event/cause and unconditional interval `marginal_probabilities` (successive cumulative differences). Aalen–Johansen additionally returns `states`, horizon-by-state `state_occupancy`, transition matrices and `first_hit_probability`; its CIF key is `first_hit`. A subject initially in a marked state has first-hit probability one already, and zero new first-hit mass at elapsed zero.

`start_time` conditions the prediction on remaining eligible at the landmark. AFT uses a stable log-survival ratio `S(start+h)/S(start)`. Impossible zero-survival conditioning fails. Aalen–Johansen requires observed landmark support for the initial state and the declared transition assumption.

Default `extrapolation="error"` rejects times outside observed support. `flat` freezes empirical cumulative hazards and AFT survival past support; this is reported as an explicit assumption. AFT alone supports `parametric` tails. Optional AFT `quantile_levels` requires that explicit parametric policy and ordered interior probabilities; output adds conditional remaining-event-time quantiles, computed from the same survival ratio. Quantile round trips are separately tested for all three distributions. The prediction response identifies whether its survival is event-free survival, first-hit survival, or a Fine–Gray selected-cause complement.
