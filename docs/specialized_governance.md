# Frozen specialist transaction histories

The Python `specialized_governance.py` example exposes `run(data=None, verify_reference=True, model_path=None)`; native R exposes `run_specialized_governance(data=NULL, verify_reference=TRUE, model_path=NULL)`. Both load an integrity-checked fitted macro artifact and five dated transaction histories. `model_path` may point to a user-supplied portable fitted-model envelope; `data` supplies the matching recipes, version identities and economic inputs. Set reference verification off only when replacing the synthetic example contracts.

The actual fitted macro model records scenario-generation provenance. The registered assessment pipeline executes the complete frozen cash-pool simulation, then composes separate PD and expected-loss components and applies a local policy with cashflow, legal and operational gates. The primary macro artifact is not misrepresented as an empirical default model. Its generated cube is explicitly frozen with the original scenario IDs, weights and consumed factor values; unrelated factors are omitted and the projected cube is sealed. A registered bundle binds those inputs, the parameter snapshot, addressed innovations and the policy. No empirical refitting occurs inside assessment execution.

The five obligors are an income-producing property, operating project, single leased aircraft, time-chartered ship and equipment lease. Independent component evidence is in the companion asset-finance example. The local history records review, finalization and legal exit. Separate observed servicing records give the contractual January 2024 coupon, a missed payment, 31-day delinquency, a restructuring proposal that does not amend the contract, and material default after 92–96 days. The resulting collateral settlements and closure dates are product-specific. Legal write-off/settlement is not borrower cure, and approval is not a funding instruction.

The original 2023 information cutoff remains attached to historical calculation. Missed-payment evidence triggers a stale assessment. Repeating the same review event is idempotent. Registering a genuinely refitted later macro version does not substitute it during historical replay. Altering the preserved event-state hash is detected. The output retains full result seals rather than hiding differences behind numerical comparison.

These are local synthetic outputs, never external publication or a lending instruction. Scenario outcomes are not observed validation labels. Additional observation-window and monitoring records are included as distinct dated data, but this governance example does not yet execute the complete monitoring, restructuring, workout-estimation or alternate-macro-method acceptance suite. It establishes frozen execution and lifecycle-history evidence, not completion of all product phases.

Default tests execute one complete history with real later-model fitting; `CREDITRATINGSYSTEM_EXTENDED_TESTS=true` executes all five. All writes, including new fitted model serialization, are explicitly caller-managed outside installed package resources.

Optional audit access: the corporate governance helper accepts return_audit_artifacts; specialized governance accepts it on its public example runner and journey helper. When true, the existing report is accompanied by the actual frozen registry, original/history requests and their actual results. Default reports remain exactly unchanged.
